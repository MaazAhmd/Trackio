# Trackio
Trackio is a powerful time-tracking application designed specifically for freelancers, allowing them to efficiently manage their time, track expenses, and streamline project workflows. The app provides an intuitive UI that simplifies tracking work hours and project-related expenses.

Users can create and manage projects, clients, and consultants. The admin can assign consultants (team members) to projects and set individual compensation—either hourly or fixed. A detailed time entries page offers filters and a wildcard search to quickly access relevant records.

The system ensures secure authentication through reCAPTCHA and two-factor authentication, while PostgreSQL (Supabase) handles secure and efficient data storage. The app also includes a dedicated login system for consultants, allowing them to track their work hours, payments, and project statuses.

## Key Features

**Time Tracking:** An interactive time-tracking screen displaying ongoing projects with input fields for logging work hours.

**Time Entries Page:** Provides a detailed list of tracked time entries, featuring filters and a wildcard search.

**Project & Consultant Management:** Allows users to create, edit, and delete projects, clients, and consultants. Admins can assign consultants to projects and define their compensation models.

**Income & Expense Tracking:** Calculates income based on projects and tracks expenses, including consultant payments.

**Consultant Login System:** Consultants have separate logins to track their assigned projects, payments, and work statuses.

**Email Notifications:** Automated emails for project updates, payments, and consultant assignments.

**Secure Authentication:** Utilizes reCAPTCHA and two-factor authentication for added security.

## Technologies Used

**Python:** Powers the backend logic, ensuring seamless data processing and integration.

**Flask:** Serves as the web framework to build the front-end and API layers with clean, reusable components.

**PostgreSQL (Supabase):** Efficient and secure database management for storing user and project data.

**SendGrid Email API:** Automates email notifications for various project and payment updates.
